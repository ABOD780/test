# 📖 منصة الاختبارات الإلكترونية الذكية
### حلقة الشهيد بلال الخدري

> منصة اختبارات إلكترونية تفاعلية وآمنة مصممة خصيصاً لحلقات تحفيظ القرآن الكريم والعلوم الشرعية، مزودة بمحرك ذكاء اصطناعي لتصحيح الأسئلة المقالية تلقائياً ونظام حماية ومراقبة متقدم.

---

* **أستاذ الحلقة**: عبد الرحمن الشميري
* **تصميم وبرمجة**: عبد الرحمن الشميري

---

### ✨ المميزات الرئيسية
* **أنواع أسئلة متنوعة**:
  * 🔵 اختيار من متعدد (MCQ)
  * 🟢 صح أو خطأ
  * 🟡 إكمال فراغات
  * 🟠 أسئلة مقالية مصححة آلياً
* **🤖 محرك تصحيح ذكي للأسئلة المقالية (AI Auto-Grader)**:
  * تحليل دلالي للغة العربية وتجريد الزوائد والأحرف.
  * مطابقة العبارات التامة (N-grams) لمحاكاة نتائج البحث بدقة.
  * احتساب الدرجة آلياً وفورياً مع تقديم تقرير بملاحظات الذكاء الاصطناعي.
* **🛡️ نظام أمان ومكافحة الغش**:
  * إلزام وضع الشاشة الكاملة (Fullscreen) طوال فترة الاختبار.
  * رصد محاولات الخروج من الصفحة أو تبديل النوافذ.
  * إرسال الاختبار وحفظ الإجابات تلقائياً عند تكرار المخالفة.
* **📊 لوحة تحكم متكاملة**:
  * إدارة الاختبارات وتفعيلها.
  * إدارة بيانات الطلاب المسجلين والسماح بإعادة الاختبار.
  * إحصائيات النتائج ومتوسط الدرجات.
* **📄 تقارير وشهادات PDF**:
  * استخراج النتيجة وشهادة الاختبار بملف PDF منسق وجاهز للطباعة والمشاركة.
* **📱 تصميم متجاوب بالكامل**:
  * تجربة استخدام فائقة السرعة والسلاسة على الهواتف الذكية والأجهزة اللوحية والحواسيب.

---

### 🚀 تشغيل المنصة ونشرها على GitHub Pages
1. افتح مستودع المشروع على GitHub.
2. اذهب إلى **Settings** > **Pages**.
3. في قسم **Branch**، اختر `main` ومجلد `/(root)`.
4. اضغط **Save** وسيصبح موقعك متاحاً على الإنترنت مجاناً عبر رابط GitHub Pages.
